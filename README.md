# Create: Sandustry · 沙金工艺

以还原《Sandustry》的设计理念与玩法为目标的 Minecraft 机械动力附属模组，目前主要服务于自制整合包。

围绕沙子、黄金与机械加工，将筛振淘金、农业、能源循环、重力加工、旋律解谜和战斗串联起来。生产线除了考虑转速与物流，还需要利用热量、月光、加工高度和物品弹跳。

项目仍在开发中，以下内容按当前代码整理。整合包可以通过配置和数据包调整配方、概率与进度。

## 玩法概览

### 沙子、淘金与考古

- **特殊沙子**：湿沙子、硬化沙子、石化沙子、烈性沙子、雷霆沙子和猫砂，各自参与不同的资源与交互机制。烈性沙子可能引发爆炸和连锁反应，雷霆沙子可能触发雷击。
- **沙化矿石**：为煤、铁、铜、金、红石、青金石、钻石、绿宝石和锌提供硬化沙子、石化沙子两组矿石变体。
- **筛振传送带**：对已套机壳的水平传送带手持溜槽右键安装筛网，让原料一边运输一边筛分。湿沙子可筛出残渣，并有概率获得金粒；黄铜机壳能提高处理效率。使用扳手可以拆除筛网并取回溜槽。
- **自动化考古**：机械手可以使用刷子参与刷掘。默认启用通用考古奖池，可疑沙子、可疑沙砾会从已加载的有效考古战利品表中抽取奖励；可刷方块默认也会在下落后保留刷掘数据。
- **猫砂生产**：成功喂食站在普通沙子上的猫，有概率将其脚下的沙子转化为可刷掘的猫砂。机械手也可以给坐在 Create 坐垫上的受伤驯服猫喂食治疗，并触发转化判定。

挖沙也有风险：**活沙**会伪装、跳跃追击，并可能寄生在玩家头部造成窒息。

### 从残渣到弗洛林能源

当前已有一条从淘金副产物延伸出的生产路线：

```text
沙子 + 水 → 湿沙子 → 筛振 → 残渣
残渣 + 熔岩灌注 → 焦化残渣 → 重力压制 → 紫金花种子
黄金耕地种植 → 紫金花瓣 → 超级加热压块 → 弗洛林电池液
弗洛林电池液 → 电池放电 → 弗洛林土壤 → 加热液化 → 弗洛林电池液
```

- **黄金农业**：包含黄金泥土、黄金耕地、可种植的黄金胡萝卜与黄金橡树。紫金花只能种在黄金耕地上，花瓣是弗洛林电池液的加工原料。
- **弗洛林电池**：以沙金机壳搭建有底、开放顶部的多方块结构，接入电池控制方块并注入弗洛林电池液，向外提供 FE 能量。结构内部的电池液在放电后会逐步凝固为弗洛林土壤。
- **土壤再液化**：弗洛林土壤受热后可以重新变成电池液，反应还会沿相连土壤传播，形成需要热量输入的能源循环。
- **工具供能**：支持绑定的工具可右键已激活的电池完成绑定，潜行右键解除绑定。绑定不限制距离，但电池所在区块必须保持加载。

沙金机壳也可用于包裹传动轴，兼顾工厂搭建与装饰。

### 重力压制与热能管理

**重力压制器**使用 FE 电力和竖直加工空间处理物品：

1. 在输出容器上方放置基座，调整工作高度，并保持加工柱内为空气。
2. 手持溜槽右键基座，在设定高度搭建输入器。
3. 从基座水平侧面输入 FE，通过上方溜槽投入原料。
4. 机器收集原料后批量加工，产物从下方输出；红石信号可暂停工作。

工作高度可在 **3～23 格**之间调整。低于配方要求的高度时需要额外耗电，因此可以用更高的厂房换取更低的加工能耗。当前配方包括将焦化残渣加工成紫金花种子，并概率产出金粒。

**热能缓冲器**可以从邻近热源吸收热量、储存并向其他缓冲器传热，也能为 Create 锅炉和加热加工提供热源。热量传递存在损耗，失去热源后会逐渐散热；下界中不自然散热，破坏后的掉落物会保留热值。接入红石信号可封闭对外热输出并停止自然散热。

### 月光、月跃石与重力构件

**月晶石碎片**由海晶碎片转化而来：在主世界午夜附近，晴天且上方能看到天空时，从含水的置物台取出海晶碎片，有概率得到月晶石碎片。机械手可以代替玩家取出，含水溜槽也参与转化机制。

月晶石可以喂给兔子，也可以由玩家食用，触发 **月亮崇拜**。在效果倒计时内完成规定次数的跳跃，就有机会获得月跃石；玩家未能及时完成会受到致命惩罚。重复喂食仍处于效果中的兔子，会使其变成杀手兔。

月跃石进一步参与两种加工：

- **月跃石板**：使用 Create 动力冲压机在不同 Y 高度加工，半成品会记录已使用的高度并累积进度。主世界目标为 320，下界目标为 128；累计值必须恰好达到目标，重复高度不推进，越界会损坏材料。在末地首次冲压月跃石可直接完成。
- **重力构件**：先通过机械手将精密构件装配到月跃石板上，再让半成品经过弹跳激活。连续弹跳会提高成功率，中断会增加损坏风险，物品提示会显示相关概率。

**月跃石块**提供不黏附的弹跳表面，可用于弹跳加工装置；已实现与 Sable 移动结构的弹跳兼容。

### 旋律谜题与蒸汽笛

将对应唱片放入唱片机播放线索，再用附近的 **Create 蒸汽笛**演奏音高序列。输入正确后会播放解答，并按谜题配置发放奖励或改变天气。

当前包含五组谜题：

| 谜题 | 完成效果 |
| --- | --- |
| Opening | 获得沙金剑 |
| Awakening | 获得对应唱片残片 |
| Healing | 获得对应唱片残片 |
| Birds | 获得对应唱片残片 |
| BigNortheastIsMyHomeland（迷幻兔脚） | 触发雷暴天气 |

谜题采用数据驱动，音序、输入时限、有效范围、奖励与天气效果均可由数据包定义。

### 沙心、武器与战斗

**沙化**会逐步产生沙心，挤占玩家或生物的有效生命上限。沙心填满生命条后会进入 **沙化之兆**倒计时，效果自然结束时受到致命沙化伤害。玩家完成一次饮用可减少部分沙心，为战斗和探索提供应对手段。

- **沙团与沙之心**：沙团可以食用，但有概率引发沙化；使用沙之心会直接增加沙心。
- **沙金剑**：带有损坏形态，可使用沙团修复，并支持机械手修复加工。
- **沙噬剑**：带有剑座、认主拔剑、休眠恢复和剑气机制。拔取无主剑需要满足沙心与沙化之兆条件，成功会付出永久生命上限代价；在沙化之兆期间可释放剑气，并与部分剑类附魔联动。
- **火箭土豆**：为土豆加农炮提供带火焰尾迹和范围爆炸的弹药，可破坏低硬度方块。


### 金选与黄金经验

- **金选食物**：与森罗物语（Kaleidoscope Cookery）联动，最高品质菜品有概率成为金选。食用后获得金选效果，在效果期间挖掘沙类方块可额外获得金粒，并提供金选蛋炒饭相关进度。
- **黄金经验**：闪电苦力怕爆炸波及 Create 经验块时，有概率将其转化为金验块。金验粒可以使用并释放经验，也可与沙之心加热搅拌制作金之心。

### 可选的世界生成与时间锁

这两项功能**默认关闭**，需要在配置中启用：

| 配置项 | 启用后的行为 |
| --- | --- |
| `worldgen.enabled` | 在新生成区块中启用地质替换，以及可疑沙子、可疑沙砾、猫砂和活沙团簇生成；已有区块不会回写。 |
| `time_bearing.enabled` | 默认锁定昼夜时间，使用已组装、有动力且满足网络应力容量要求的时钟轴承解除时间锁。 |

时间锁模式下，默认需要至少 **500,000 SU** 的网络总容量。容量严格超过 **4,000,000 SU** 后，昼夜推进速度会按输入转速和配置倍率计算。睡觉能否跳过夜晚、初始时间和推进速率也可配置。

## 模组联动

| 模组 | 已实现的主要联动 |
| --- | --- |
| Create | 筛振传送带、机械手考古与喂猫、动力冲压、沙金套壳、热源、土豆加农炮、蒸汽笛与时钟轴承 |
| JEI | 筛振、重力压制、随机树苗搅拌和重力构件装配展示 |
| Jade | 重力压制器状态信息 |
| Botany Pots | 黄金土壤、黄金胡萝卜与紫金花种植配方 |
| Create: Connected | 黄铜溜槽筛振兼容 |
| Create Stuff 'N Additions | 弗洛林工具、黄铜装备及相关装备行为兼容 |

除核心玩法依赖的 Create 外，上表中的扩展联动按对应模组是否安装生效。开发环境中使用的 `localRuntime` 模组不代表游玩时必须全部安装。

## 配置与整合包定制

公共配置由 NeoForge 生成，主要包括世界生成、弗洛林电池能量换算、重力压制器高度补偿、特殊沙子触发概率、活沙行为、金选、月晶转化、月亮崇拜和时间锁等选项。

可在 [配方目录](src/main/resources/data/createsandustry/recipe) 与 [旋律谜题目录](src/main/resources/data/createsandustry/melody_puzzle) 查看现有数据。整合包可通过数据包覆盖配方、战利品、标签和谜题；具体产出与数值以当前整合包配置及游戏内 JEI 为准。

## 开发与构建

使用 JDK 21，在项目根目录运行：

```powershell
# 构建，产物位于 build/libs/
.\gradlew.bat build

# 运行已有的 GameTests
.\gradlew.bat runGameTestServer

# 启动开发客户端
.\gradlew.bat runClient
```

Linux / macOS 对应使用 `./gradlew`。

`libs/` 为被 Git 忽略的本地依赖目录。当前构建脚本仍引用以下 JAR，新克隆项目后需要按文件名补齐：

```text
libs/
  kaleidoscopecookery-1.6.0-neoforge+mc1.21.1.jar
  botanypots-neoforge-1.21.1-21.1.44.jar
  bookshelf-neoforge-1.21.1-21.1.81.jar
  prickle-neoforge-1.21.1-21.1.11.jar
```

依赖与开发运行配置见 [build.gradle](build.gradle)，版本参数见 [gradle.properties](gradle.properties)，模块划分见 [项目结构说明](ARCHITECTURE.md)。
