## 人工检查步骤

- [ ] 打开 'docs/sandified_ores/preview.png'，逐行核对 8 列：普通源矿、石基底、硬化沙基底、硬化结果、深层源矿、深板岩基底、石化沙基底、石化结果。
- [ ] 核对矿物颜色、像素轮廓、位置与源矿一致，且背景没有残留石头/深板岩像素块。
- [ ] 核对不确定像素列表；若其中包含矿物同色像素，按报告坐标调整遮罩或人工修补。
- [ ] 核对 16×16 尺寸、透明通道以及所有模型/方块状态引用。
