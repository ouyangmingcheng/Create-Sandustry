# Opening 唱片神秘转化 JEI 条目

Opening 唱片本身已经是谜题奖励沙金剑的来源，不需要额外炼药锅配方。

本条目只用于在 Create 的“神秘转化 / Mystery Conversion”JEI 分类中展示关系：

```text
createsandustry:music_disc_opening -> createsandustry:sand_sword
```

注册位置：

```text
src/main/java/com/minechai/create_sandustry/content/compat/jei/SandustryJeiPlugin.java
```

实际奖励仍由 `opening` 音乐谜题完成后发放。
